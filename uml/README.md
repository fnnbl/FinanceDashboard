# UML-Diagramme

Dieser Ordner enthält alle UML-Diagramme des Projekts gemäß den Projektanforderungen.

## Geforderte UML-Diagramme

### SD - Softwareentwicklung und Datenmanagement

1. **Klassendiagramm**
   - Backend-Struktur (Models, Schemas, CRUD, Services)
   - Darstellung der objektorientierten Architektur
   - Beziehungen zwischen Klassen (Vererbung, Komposition, Aggregation)
   - Attribute und Methoden der wichtigsten Klassen

2. **Aktivitätsdiagramm**
   - Budget-Plan erstellen, Budget-Posten anlegen, Berechnung monatlicher Beträge

3. **Sequenzdiagramm**
   - Login-Prozess, Budget-Plan-Erstellung

### VP - Entwicklung vernetzter Prozesse

4. **Use-Case-Diagramm**
   - Registrierung, Login, Plan verwalten, Budget-Posten verwalten, Auswertungen anzeigen
   - Include/Extend-Beziehungen

5. **Zustandsdiagramm**
   - Zustände eines Budget-Plans, Benutzer-Session, Budget-Posten-Lebenszyklus
   - Events und Transitionen

# Testprotokolle

Dieser Ordner enthält **Testberichte und Testprotokolle** (KEINE Testskripte) gemäß den Anforderungen für das Fach VP.

## Struktur

- **Testplanung** - Geplante Testfälle und Testszenarien
- **Testprotokolle** - Ausgefüllte Testprotokolle mit Ergebnissen
- **Fehlerdokumentation** - Gefundene Fehler und deren Behebung

## Testarten

### Backend-Tests
- **Unit-Tests** - Einzelne Funktionen und Methoden (z.B. CRUD-Operationen, Berechnungslogik)
- **Integrationstests** - API-Endpunkt-Tests (FastAPI Testclient)

### Manuelle Tests
- **UI/UX-Tests** - Benutzeroberfläche und Bedienbarkeit
- **Browser-Kompatibilität** - Tests in verschiedenen Browsern
- **Responsive Design** - Tests auf verschiedenen Bildschirmgrößen

## Dateien

| Datei | Beschreibung |
|-------|--------------|
| `Testplan.md` | Übersicht aller geplanten Testfälle
| `Testprotokoll_Backend.md` | Backend-Tests
| `Testprotokoll_Manuell.md` | Manuelle Tests
| `Fehlerprotokoll.md` | Dokumentation gefundener Bugs

## Hinweise

- **Testskripte** gehören in die jeweiligen Repositories (Backend/Frontend), NICHT hier
- Hier werden nur die **Testprotokolle** (Dokumentation der Testergebnisse) abgelegt

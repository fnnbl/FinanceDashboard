### 2.2 Frontend - Grundstruktur

React-Projektstruktur aufgesetzt mit:
- React Router v6 (BrowserRouter, ProtectedRoute)
- ThemeContext (Light/Dark Mode mit localStorage-Persistenz)
- AuthContext (JWT-Token-Verwaltung, automatischer Login-Check)
- Navbar mit Theme-Toggle
- Design-System: CSS-Variablen, Roboto Mono + Rubik, CSS Modules pro Seite
- Datenbankwechsel von Railway auf Supabase PostgreSQL

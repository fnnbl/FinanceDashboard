## 2. Durchgeführte Arbeiten

### 2.1 Backend-Grundstruktur

- FastAPI-Projekt mit sauberer Schichtarchitektur aufgesetzt:
  - `core/` (Config, Database, Security)
  - `models/` (SQLAlchemy ORM)
  - `schemas/` (Pydantic Validation)
  - `crud/` (Datenbankoperationen)
  - `api/v1/endpoints/` (REST-Endpoints)
- Async SQLAlchemy mit PostgreSQL (Railway) angebunden
- Virtual Environment mit allen Dependencies eingerichtet

### 2.2 Implementierte User Stories

### 2.3 Erstellte Models

- **User** - Email, Passwort (bcrypt), Name
- **Plan** - Name, Beschreibung, FK zu User
- **Category** - Name, Typ (income/expense), is_system (Model angelegt)
- **BudgetItem** - Betrag, Zahlungsrhythmus, Kategorie (Model angelegt)

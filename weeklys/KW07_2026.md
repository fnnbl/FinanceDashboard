## 3. Probleme & Herausforderungen

### 4.1 User Stories Format
**Problem:** Lehrer fordern XLSX-Format, aber User Stories wurden in Markdown dokumentiert (bessere Versionskontrolle mit Git).

**Lösung:** Konvertierung in Excel-Format.

### 4.2 Repository-Struktur
**Entscheidung:** 3 separate Repositories statt Monorepo, um:
- Klare Trennung von Doku, Backend und Frontend
- Bessere Übersicht im Projektboard
- Unabhängige Deployment-Pipelines

# Wöchentliche Berichte

Dieser Ordner enthält die wöchentlichen Projektberichte für die Berufsschule.

## Format

Jeder Wochenbericht enthält folgende Informationen:

- **Kalenderwoche:** KW XX/YYYY
- **Zeitraum:** DD.MM.YYYY - DD.MM.YYYY
- **Durchgeführte Tätigkeiten:**
  - Aufgabe 1
  - Aufgabe 2
  - ...
- **Erreichte Meilensteine:**
  - Meilenstein 1
  - ...
- **Probleme/Herausforderungen:**
  - Problem 1 und Lösung
  - ...
- **Nächste Schritte:**
  - Geplante Aufgaben für nächste Woche

## Dateinamen

Format: `KW{Nummer}_{Jahr}.md`

Beispiel:
- `KW06_2025.md`
- `KW07_2025.md`

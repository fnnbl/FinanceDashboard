# Dokumentation - Finance Dashboard

Dieser Ordner enthält die vollständige Projektdokumentation gemäß den Anforderungen für das Berufsschulprojekt.

## Inhalte nach Fachbereich

### GI - Gestaltung von IT-Dienstleistungen

1. **Projektantrag** (`Projektantrag_Blaurock_Fynn.pdf`)
   - Offizieller Projektantrag für die Berufsschule
   - Projektbeschreibung und Zielsetzung
   - Zeitplan und Meilensteine

2. **User Stories** (`USER_STORIES.md`)
   - Vollständige User Stories mit Akzeptanzkriterien
   - Priorisierung (Must-Have, Should-Have, Nice-to-Have)
   - Sprint-Planung (MVP-Phasen)

3. **Benutzerdokumentation** (`Benutzerdokumentation.md`)
   - **Installation:** Setup-Anleitung für Backend und Frontend
   - **Nutzung:** Benutzerhandbuch mit Anleitungen

4. **Projektpräsentation** (`Projektpräsentation.pptx`)
   - Abschlusspräsentation
   - Inhalte: Projektidee, Use Cases, Live-Demo, Tech Stack, Architektur, Code Highlights, Datenbank, UML, Tests, Fazit
